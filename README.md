# Product Line Profitability & Margin Performance Analysis for Nassau Candy Distributor

## Description
This project analyzes sales data of Nassau Candy Distributor and presents insights using an interactive Streamlit dashboard.

## Features
- Data cleaning and preprocessing  
- Sales data analysis  
- Interactive charts and visualizations  
- Streamlit dashboard  

## Tech Stack
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Plotly  
- Streamlit  

## Files
- app.py  
- Product_Profitability_Analysis_Nassau_Candy.ipynb  
- Nasssau Candy Distributor.csv  
- requirements.txt  

##  How to Run

### 1. Clone Repo
git clone https://github.com/ruksar16/product-profitability-margin-analysis.git  
cd product-profitability-margin-analysis 

### 2. Install Requirements
pip install -r requirements.txt  

### 3. Run App
streamlit run app.py
